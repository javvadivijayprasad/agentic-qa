## Decisions taken (flag if you disagree)

- **Manifest before capability.** A tool the manifest does not name is destructive and refused,
  even if the server calls it `get_something`. Servers cannot smuggle capabilities in; A5 admits
  them one by one from the observed list.
- **No tool names from memory.** `DEFAULT_MANIFEST` has zero `ado.*`/`playwright.*` entries on
  purpose; the paper needs the names to be provenanced to a recorded `listTools()` call.
- **Versions unpinned until observed.** `latest` now; after your run I pin the resolved versions
  in `servers.ts` and record them in the report.
- **PAT only in env.** `AZURE_DEVOPS_PAT` is passed to the child process environment, never as an
  argument (argv is visible in process listings and in the ledger's `call` events).
- **`fs` writes are workspace-bounded and `write_workspace`** (execute by default) — that is the
  agent's scratch area; branch/record writes still go through ask.
