## Decisions taken (flag if you disagree)

- **Out-of-scope is a refusal, not an ask.** Even if the table says `ask`, a call touching a work
  item / repo / test plan outside the allow-list is refused and logged. Approval cannot widen scope.
- **Protected branches are destructive**, not merely refused: they show up as `destructive → refuse`
  so the ledger makes the severity visible.
- **Missing scope argument = refuse.** If a tool declares `scopeArgs.workItem: "id"` and the model
  omits `id`, the gate refuses rather than guessing.
- **Terminal default is No.** Enter or anything but `y`/`yes` denies.
- **File approver timeout is a denial by "timeout"**, which the loop turns into `blocked` (handoff B4).
- Scrub is a library in A3; it is not yet applied anywhere because no prompt leaves the process yet.
