## Decisions taken (flag if you disagree)

- A model decision may contain several calls (parallel tool use). Each gets its own `inference`
  and `policy` event; all `ask`s in one cycle share one approval.
- Refusal is not a stop: the refused call is fed back to the model as history; budgets bound the
  loop. A run ends `blocked` only when an approval is denied and nothing else could run that cycle.
- Verifier gaps give the model exactly one more round, then `blocked`.
- `context` is rebuilt and logged every cycle (hashes + estimated tokens), not once per run.
